# 🌍 Currency Converter Web App

A simple and interactive currency converter that allows users to convert between different currencies using real-time exchange rates from [CurrencyAPI](https://www.currencyapi.com/).

![Currency Converter Screenshot](https://user-images.githubusercontent.com/your-username/your-image.png)

---

## 🚀 Features

- Real-time currency conversion using `currencyapi.com`
- Dynamic currency selection dropdowns
- Country flags update automatically based on selected currency
- Built-in support for two lifelines (optional feature extension)
- Responsive and clean UI

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
- [CurrencyAPI](https://www.currencyapi.com/)
- [FlagsAPI](https://flagsapi.com/)
